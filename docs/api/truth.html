truth

truth.py - Score any recording against the waveform the generator actually emitted, and produce corrected timestamps with a stated confidence.

THE PRINCIPLE

The PRE-Sync signal is deterministic, so the waveform that was on the wire can be regenerated exactly. That makes it ground truth: a recording is judged against what was emitted, not against another recording. This matters because comparing two recordings to each other cannot say which of them is at fault — and on real data, both were.

WHAT IT MEASURES, SEPARATELY

A recording can be wrong in four ways at once, and they need different fixes:

OFFSET a constant lag. Correctable exactly. DRIFT the recorder's clock running fast or slow. Correctable, but only if measured; a constant offset will not hold across a long trial. JITTER what is left once offset and drift are removed. Irreducible. This is the recorder's real timing precision and it sets the floor on any analysis. LOSS transitions that never made it into the file at all. Not a timing error and not correctable — the data is gone. Reported separately so it is never confused with poor timing.

Reporting a single "error" number conflates all four and hides which one is the problem.

WHAT MAKES THE LOCK ROBUST

Finding where a recording sits in a free-running generator's output is the hard part, and the obvious approaches fail on real data:

  • The generator is usually ALREADY RUNNING when recording starts. Assuming the recording begins at template t=0 reports "no seed matches" on a perfectly good file. Two real recordings from one continuous run were located at 17.9 min and 41.1 min into it.

  • A fixed millisecond tolerance cannot survive drift or loss. At 300 ppm the accumulated position slides past any threshold, and a dropped event makes one interval the sum of two. Matching therefore compares interval RATIOS, so drift scales out.

  • Counting how many windows agree is the wrong score. A recording with a damaged opening locks weakly by that measure while being perfectly alignable. Candidates are scored by ANCHORED COVERAGE instead: anchor there, and count how many of the recording's events land on a real transition. On a wireless stream that scored "NO LOCK" under window voting, coverage scoring placed 100% of its events correctly.

Usage:

from truth import score, correct

r = score(edge_times) # both edges recorded r = score(trigger_times, both_edges=False) # rises only print(r)

t_true, conf = correct(edge_times, r) # corrected timestamps

Dependencies: numpy, and timecode.py for template generation.

100@dataclass
101class TruthReport:
102    """How one recording compares to what the generator emitted."""
103    locked: bool = False
104    note: str = ""
105
106    start_s: float = float("nan")      # where in the run the recording begins
107    coverage: float = float("nan")     # fraction of the recording's own events
108                                       # that land on a real transition
109
110    n_emitted: int = 0                 # transitions the generator produced
111    n_recorded: int = 0                # transitions in the file
112    n_captured: int = 0                # emitted ones the file actually has
113    n_spurious: int = 0                # recorded ones that match nothing
114    capture_pct: float = float("nan")
115    lost_at_s: list = field(default_factory=list)
116
117    offset_ms: float = float("nan")
118    drift_ppm: float = float("nan")
119    jitter_sd_ms: float = float("nan")
120    jitter_p95_ms: float = float("nan")
121    jitter_max_ms: float = float("nan")
122    raw_sd_ms: float = float("nan")    # before correcting offset and drift
123
124    # Timing measured on transitions FAR from any loss. A dropout does not
125    # only remove its own transition: the ones on either side of a gap are
126    # the most likely to be mistimed, and including them attributes the
127    # dropout's damage to the recorder's timing. Separating the two is what
128    # distinguishes "loses data but times the rest perfectly" from "times
129    # everything poorly" — on real data one stream went 2.44 -> 0.46 ms when
130    # its dropout-adjacent transitions were excluded, while another barely
131    # moved (2.49 -> 2.58), which is the difference between an intermittent
132    # interruption and a genuinely noisy link.
133    clean_n: int = 0
134    clean_jitter_sd_ms: float = float("nan")
135    clean_jitter_max_ms: float = float("nan")
136    clean_offset_ms: float = float("nan")
137    clean_drift_ppm: float = float("nan")
138
139    span_s: float = float("nan")
140    _fit: tuple = (0.0, 0.0)           # (drift slope, offset) in truth time
141    _t0: float = 0.0                   # truth-time origin the fit is about
142    _lock_off: float = 0.0             # recording clock - truth clock

144    def __str__(self):
145        if not self.locked:
146            return f"NOT LOCATED — {self.note}"
147        L = [f"  located {self.start_s/60:.1f} min into the generator's run  "
148             f"({self.coverage*100:.0f}% of recorded events are real transitions)",
149             f"  span {self.span_s:.1f} s",
150             "",
151             f"  CAPTURE   {self.n_captured} of {self.n_emitted} emitted "
152             f"({self.capture_pct:.1f}%)"
153             + (f"   — {self.n_emitted-self.n_captured} LOST"
154                if self.n_captured < self.n_emitted else "   — none lost"),
155             ]
156        if self.n_spurious:
157            L.append(f"            {self.n_spurious} recorded event(s) match no "
158                     f"emitted transition")
159        L += ["",
160              f"  OFFSET    {self.offset_ms:+.2f} ms      (constant; correctable)",
161              f"  DRIFT     {self.drift_ppm:+.1f} ppm = {self.drift_ppm*60/1000:+.2f} ms/min"
162              f"   (correctable)",
163              f"  JITTER    sd {self.jitter_sd_ms:.2f} ms, p95 "
164              f"{self.jitter_p95_ms:.2f}, max {self.jitter_max_ms:.2f}"
165              f"   (irreducible — this is the precision floor)",
166              f"            uncorrected residual was sd {self.raw_sd_ms:.2f} ms"]
167        if self.clean_n and np.isfinite(self.clean_jitter_sd_ms):
168            worse = self.jitter_sd_ms / max(self.clean_jitter_sd_ms, 1e-9)
169            L += [f"",
170                  f"  AWAY FROM LOSSES ({self.clean_n} transitions clear of any gap)",
171                  f"            offset {self.clean_offset_ms:+.2f} ms, drift "
172                  f"{self.clean_drift_ppm:+.1f} ppm, jitter sd "
173                  f"{self.clean_jitter_sd_ms:.2f} ms, max "
174                  f"{self.clean_jitter_max_ms:.2f} ms",
175                  f"            {'the dropouts account for most of the apparent jitter'
176                                 if worse > 2 else
177                                 'jitter is spread through the recording, not just at gaps'}"
178                  f" ({self.jitter_sd_ms:.2f} -> {self.clean_jitter_sd_ms:.2f} ms)"]
179        L += ["",
180              f"  VERDICT   {self.verdict}"]

183    @property
184    def verdict(self) -> str:
185        if not self.locked:
186            return "could not be located in the generator's output"
187        lost = 100 - self.capture_pct
188        if lost > 10 and self.jitter_sd_ms > 5:
189            return (f"DEGRADED — {lost:.0f}% of transitions lost and "
190                    f"{self.jitter_sd_ms:.1f} ms jitter")
191        if lost > 10:
192            return (f"LOSSY BUT WELL TIMED — {lost:.0f}% lost, though what "
193                    f"arrived is good to {self.jitter_sd_ms:.2f} ms")
194        if self.jitter_sd_ms > 5:
195            return (f"COMPLETE BUT IMPRECISE — nothing lost, but "
196                    f"{self.jitter_sd_ms:.1f} ms jitter")
197        return (f"GOOD — {self.capture_pct:.0f}% captured, "
198                f"{self.jitter_sd_ms:.2f} ms jitter after correction")

201# One PRE-Sync duration quantum. The generator can only emit multiples of
202# this, so it is the natural unit for timing error: a recorder inside +/-0.5
203# units can never be assigned to the wrong tick, whatever the millisecond
204# figure happens to be.
205STEP_MS = 1.0   # config.h DURATION_STEP_MS (protocol 3; was 5.0)
206
207# A transition off by more than this many quanta is not jitter — it is a
208# single corrupted timestamp, and averaging it into a standard deviation
209# misrepresents the recorder. One sample 28 ms out took a stream's apparent
210# jitter from 0.53 ms to 2.44 ms; the other 142 were fine.
211GROSS_UNITS = 3.0
212
213# Consecutive missing transitions that count as an outage rather than
214# scattered misses. An outage is ONE event however long, and is not a timing
215# property: a 7.7 s stall and steady low-grade loss are different faults
216# needing different responses.
217OUTAGE_RUN = 3
218OUTAGE_GAP_S = 2.0

221def classify(edge_times, both_edges=True, **kw):
222    """Separate the four things that go wrong, so none can hide inside another.
223
224    Returns a dict with, kept strictly apart:
225
226      jitter      spread of the well-behaved transitions, in ms AND in
227                  PRE-Sync quanta. This is the recorder's real precision.
228      gross       individual transitions off by more than GROSS_UNITS. Counted
229                  and listed, never averaged into jitter.
230      outages     runs of consecutive missing transitions — the stream
231                  stopped. Reported as events with start, end and duration.
232      isolated    single missing transitions with intact neighbours.
233
234    Why bother: a 7.7 s stall, four scattered bad timestamps, and genuine
235    link noise all appear as "jitter" and "% lost" if lumped together, and
236    the same recording then reports anywhere from 0.5 ms to 2.6 ms depending
237    on how it was sliced. Separated, each number is stable and points at a
238    different fix.
239    """
240    r = score(edge_times, both_edges=both_edges, **kw)
241    if not r.locked:
242        return {"locked": False, "note": r.note}
243
244    T = _template(both_edges, kw.get("seed", SEED), kw.get("hours", SEARCH_HOURS))
245    pred = np.asarray(edge_times, float) - r._lock_off
246    pred.sort()
247    tr = T[(T >= pred[0]) & (T <= pred[-1])]
248    t0 = tr[0]
249
250    matched, errs, lost = [], [], []
251    for x in tr:
252        j = int(np.argmin(np.abs(pred - x)))
253        if abs(pred[j] - x) < MATCH_WINDOW_S:
254            matched.append(x - t0)
255            errs.append((pred[j] - x) * 1000)
256        else:
257            lost.append(x - t0)
258    matched = np.asarray(matched); errs = np.asarray(errs)
259    lost = np.asarray(lost)
260
261    slope, icept = np.polyfit(matched, errs / 1000, 1)
262    res = (errs / 1000 - (slope * matched + icept)) * 1000
263
264    # Outages: runs of consecutive losses.
265    outages, isolated = [], []
266    if len(lost):
267        grp = [[lost[0]]]
268        for x in lost[1:]:
269            if x - grp[-1][-1] <= OUTAGE_GAP_S:
270                grp[-1].append(x)
271            else:
272                grp.append([x])
273        for g in grp:
274            if len(g) >= OUTAGE_RUN:
275                outages.append({"start_s": float(g[0]), "end_s": float(g[-1]),
276                                "duration_s": float(g[-1] - g[0]),
277                                "n_missed": len(g)})
278            else:
279                isolated += [float(x) for x in g]
280
281    gross_m = np.abs(res) > GROSS_UNITS * STEP_MS
282    clean = res[~gross_m]
283
284    return {
285        "locked": True,
286        "n_emitted": len(tr), "n_captured": len(matched),
287        "offset_ms": float(icept * 1000),
288        "drift_ppm": float(slope * 1e6),
289        "jitter_sd_ms": float(clean.std()),
290        "jitter_max_ms": float(np.abs(clean).max()) if len(clean) else float("nan"),
291        "jitter_sd_units": float(clean.std() / STEP_MS),
292        "jitter_max_units": float(np.abs(clean).max() / STEP_MS) if len(clean) else float("nan"),
293        "within_half_unit_pct": float(100 * np.mean(np.abs(clean) < STEP_MS / 2)),
294        "n_gross": int(gross_m.sum()),
295        "gross_at_s": [float(t) for t in matched[gross_m]],
296        "gross_ms": [float(v) for v in res[gross_m]],
297        "outages": outages,
298        "n_outage_missed": int(sum(o["n_missed"] for o in outages)),
299        "outage_s": float(sum(o["duration_s"] for o in outages)),
300        "n_isolated": len(isolated),
301        "isolated_at_s": isolated,
302    }

305def report(c, name=""):
306    """Print a classify() result."""
307    if not c.get("locked"):
308        print(f"{name}: NOT LOCATED — {c.get('note','')}"); return
309    lost = c["n_emitted"] - c["n_captured"]
310    print(f"\n{name}")
311    print(f"  captured        {c['n_captured']}/{c['n_emitted']} "
312          f"({100*c['n_captured']/c['n_emitted']:.1f}%)")
313    print(f"  offset          {c['offset_ms']:+.2f} ms          (constant — correctable)")
314    print(f"  drift           {c['drift_ppm']:+.0f} ppm "
315          f"({c['drift_ppm']*60/1000:+.2f} ms/min)  (correctable)")
316    print(f"  JITTER          sd {c['jitter_sd_ms']:.2f} ms = {c['jitter_sd_units']:.3f} quanta, "
317          f"max {c['jitter_max_units']:.2f} quanta")
318    print(f"                  {c['within_half_unit_pct']:.1f}% land within half a quantum "
319          f"(= on the correct 5 ms tick)")
320    if c["n_gross"]:
321        print(f"  GROSS ERRORS    {c['n_gross']} transition(s) off by >{GROSS_UNITS:.0f} quanta: "
322              + ", ".join(f"{t:.1f}s ({v:+.0f} ms)"
323                          for t, v in zip(c['gross_at_s'], c['gross_ms']))[:90])
324        print(f"                  excluded from jitter — these are corrupt timestamps, "
325              f"not spread")
326    if c["outages"]:
327        print(f"  OUTAGES         {len(c['outages'])} event(s), "
328              f"{c['outage_s']:.1f}s total, {c['n_outage_missed']} transitions:")
329        for o in c["outages"]:
330            print(f"                    {o['start_s']:.1f}-{o['end_s']:.1f}s "
331                  f"({o['duration_s']:.1f}s, {o['n_missed']} missed)")
332    if c["n_isolated"]:
333        print(f"  ISOLATED MISSES {c['n_isolated']}")
334    if not c["outages"] and not c["n_gross"] and c["n_isolated"] <= 2:
335        print(f"  -> clean: timing good to {c['jitter_sd_units']:.2f} quanta, no structural loss")

341def _template(both_edges=True, seed=SEED, hours=SEARCH_HOURS):
342    # Cached: the template depends only on (seed, duration, polarity) and is
343    # identical for every stream in a session. Regenerating six hours of it
344    # per stream cost 1.5 s each and dominated the runtime — eight streams
345    # spent more time rebuilding the same array than analysing the data.
346    key = (bool(both_edges), seed, hours)
347    if key in _TEMPLATE_CACHE:
348        return _TEMPLATE_CACHE[key]
349    times, levels = tc.generate_template(
350        seed=seed, duration_s=hours * 3600,
351        min_high=MIN_HIGH_MS, max_high=MAX_HIGH_MS,
352        min_low=MIN_LOW_MS, max_low=MAX_LOW_MS,
353        tc_enabled=False, run_id=1)
354    T = np.asarray(times, float) / 1000.0
355    if not both_edges:
356        # A trigger line records one polarity only.
357        T = T[np.asarray(levels, int) == 1]
358    _TEMPLATE_CACHE[key] = T
359    return T

362def _locate(e, T, chunk=CHUNK, ratio_tol=RATIO_TOL, match_s=MATCH_WINDOW_S):
363    """Where in T does the recording e sit? Returns (offset, coverage).
364
365    Candidates come from interval-ratio matching, and are scored by how many
366    of the recording's events land on a real transition once anchored there —
367    not by how many windows agree, which under-rates a recording whose
368    opening is damaged.
369    """
370    iv = np.diff(e)
371    TI = np.diff(T)
372    if len(iv) < chunk or len(TI) < chunk:
373        return None
374    W = np.lib.stride_tricks.sliding_window_view(TI, chunk)
375
376    # COARSE THEN FINE.
377    #
378    # Six hours of template is ~78,000 windows, and comparing every probe
379    # window against all of them is 25 million comparisons per stream — 8.7 s
380    # of Python loop, which made eight streams take over a minute.
381    #
382    # A single probe window is enough to find the neighbourhood: the sequence
383    # is pseudo-random, so a matching 8-interval run is already almost unique.
384    # So use ONE probe to narrow the template to a small region, then run the
385    # full multi-probe vote only inside it. Three earlier attempts at this
386    # (striding the probes, caching the template, deduplicating candidates)
387    # each made it slower, because they trimmed the cheap part and left the
388    # 25-million-comparison loop intact.
389    def _score(off):
390        pred = e - off
391        k = np.clip(np.searchsorted(T, pred), 1, len(T) - 1)
392        d = np.minimum(np.abs(T[k] - pred), np.abs(T[k - 1] - pred))
393        return int((d < match_s).sum())
394
395    probe0 = iv[:chunk]
396    rel0 = np.max(np.abs(W - probe0) / np.maximum(probe0, 1e-3), axis=1)
397    seeds = np.flatnonzero(rel0 < ratio_tol)
398    if not len(seeds):
399        # Opening window is damaged; fall back to scanning a few probes.
400        for r0 in range(0, min(len(iv) - chunk + 1, 40)):
401            p = iv[r0:r0 + chunk]
402            rel = np.max(np.abs(W - p) / np.maximum(p, 1e-3), axis=1)
403            hit = np.flatnonzero(rel < ratio_tol)
404            if len(hit):
405                seeds = hit - r0 + 0            # express as index of probe 0
406                seeds = seeds[seeds >= 0]
407                break
408    if not len(seeds):
409        return None
410
411    best = None
412    for j0 in seeds[:200]:
413        off = e[0] - T[j0]
414        hit = _score(off)
415        if best is None or hit > best[0]:
416            best = (hit, off)
417    if best is None:
418        return None
419
420    # Refine: re-anchor on the edge nearest the middle of the recording, which
421    # is less sensitive to a damaged start or end than the first edge is.
422    mid = len(e) // 2
423    pred = e - best[1]
424    j = int(np.clip(np.searchsorted(T, pred[mid]), 1, len(T) - 1))
425    for jj in (j - 1, j, j + 1):
426        if 0 <= jj < len(T):
427            off = e[mid] - T[jj]
428            hit = _score(off)
429            if hit > best[0]:
430                best = (hit, off)
431    return best[1], best[0] / len(e)

434def score(edge_times, both_edges=True, seed=SEED, hours=SEARCH_HOURS,
435          match_s=MATCH_WINDOW_S, upto_s=None, guard_s=1.0) -> TruthReport:
436    """Judge one recording against the emitted waveform.
437
438    both_edges: False for a trigger line that logs only rising transitions.
439    upto_s:     analyse only the first N seconds — useful for characterising
440                timing on a clean stretch before any loss begins, since a
441                dropout inflates every statistic computed across it.
442    guard_s:    transitions within this of a lost one are excluded from the
443                "clean" statistics reported alongside the overall ones.
444    """
445    r = TruthReport()
446    e = np.sort(np.asarray(edge_times, float).ravel())
447    if len(e) < CHUNK + 2:
448        r.note = f"only {len(e)} transitions; need at least {CHUNK+2}"
449        return r
450
451    T = _template(both_edges, seed, hours)
452    loc = _locate(e, T, match_s=match_s)
453    if loc is None:
454        r.note = (f"no part of this recording matches {hours:g} h of the "
455                  f"generator's output — either it is not this signal, or it "
456                  f"is too corrupted for any window to match")
457        return r
458    off, cov = loc
459    r.locked = True
460    r.coverage = cov
461
462    pred = e - off
463    if upto_s is not None:
464        pred = pred[pred <= pred[0] + upto_s]
465    r.start_s = float(pred[0])
466    r.span_s = float(pred[-1] - pred[0])
467
468    truth = T[(T >= pred[0]) & (T <= pred[-1])]
469    r.n_emitted = len(truth)
470    r.n_recorded = len(pred)
471
472    pairs, lost = [], []
473    for tt in truth:
474        k = int(np.argmin(np.abs(pred - tt)))
475        if abs(pred[k] - tt) < match_s:
476            pairs.append((tt, pred[k]))
477        else:
478            lost.append(float(tt - truth[0]))
479    if len(pairs) < 3:
480        r.locked = False
481        r.note = "located, but too few transitions matched to characterise"
482        return r
483
484    P = np.array(pairs)
485    tt, rec = P[:, 0], P[:, 1]
486    r.n_captured = len(P)
487    r.capture_pct = 100.0 * len(P) / max(r.n_emitted, 1)
488    r.lost_at_s = lost
489    r.n_spurious = max(0, r.n_recorded - len(P))
490
491    err = rec - tt
492    r.raw_sd_ms = float(err.std() * 1000)
493
494    # Decompose: a straight line through the error IS the offset and drift.
495    slope, intercept = np.polyfit(tt - tt[0], err, 1)
496    jit = (err - (slope * (tt - tt[0]) + intercept)) * 1000
497    r.offset_ms = float(intercept * 1000)
498    r.drift_ppm = float(slope * 1e6)
499    r.jitter_sd_ms = float(jit.std())
500    r.jitter_p95_ms = float(np.percentile(np.abs(jit), 95))
501    r.jitter_max_ms = float(np.abs(jit).max())
502    # Store the correction in the RECORDING's own clock, so correct() can be
503    # applied to raw timestamps without the caller having to subtract the
504    # lock offset first. Folding `off` into the intercept was wrong: the
505    # drift term is measured against truth-time t0, so applying it to a raw
506    # timestamp evaluated the slope at the wrong origin and made timing
507    # 11x worse than doing nothing.
508    r._lock_off = float(off)
509    r._fit = (float(slope), float(intercept))
510    r._t0 = float(tt[0])
511
512    # Re-measure using only transitions well clear of any loss.
513    if lost:
514        lost_t = np.asarray(lost) + truth[0]
515        far = np.array([np.min(np.abs(lost_t - t)) > guard_s for t in tt])
516    else:
517        far = np.ones(len(tt), bool)
518    if far.sum() >= 5:
519        ct, cr = tt[far], rec[far]
520        cs, ci = np.polyfit(ct - ct[0], cr - ct, 1)
521        cj = ((cr - ct) - (cs * (ct - ct[0]) + ci)) * 1000
522        r.clean_n = int(far.sum())
523        r.clean_offset_ms = float(ci * 1000)
524        r.clean_drift_ppm = float(cs * 1e6)
525        r.clean_jitter_sd_ms = float(cj.std())
526        r.clean_jitter_max_ms = float(np.abs(cj).max())
527    else:
528        r.clean_n = int(far.sum())
529    return r

532def correct(sample_times, rep: TruthReport):
533    """Corrected timestamps, on the generator's timeline, plus a confidence.
534
535    Removes the measured offset and drift. What remains is the jitter, which
536    is why the confidence returned is the jitter — it is the honest bound on
537    how well any timestamp can be placed, and it does not shrink because the
538    offset was removed.
539
540    Returns (corrected_times, confidence_ms).
541    """
542    if not rep.locked:
543        raise ValueError("cannot correct with an unlocked recording")
544    slope, intercept = rep._fit
545    t = np.asarray(sample_times, float)
546    # Recording clock -> truth clock, then remove the fitted drift and offset.
547    # The drift slope was measured against truth time, so it must be evaluated
548    # there too.
549    on_truth = t - rep._lock_off
550    return on_truth - (slope * (on_truth - rep._t0) + intercept), rep.jitter_sd_ms

224
225    Returns a dict with, kept strictly apart:
226

228                  PRE-Sync quanta. This is the recorder's real precision.

516        far = np.array([np.min(np.abs(lost_t - t)) > guard_s for t in tt])
517    else:
518        far = np.ones(len(tt), bool)
519    if far.sum() >= 5:
520        ct, cr = tt[far], rec[far]
521        cs, ci = np.polyfit(ct - ct[0], cr - ct, 1)
522        cj = ((cr - ct) - (cs * (ct - ct[0]) + ci)) * 1000
523        r.clean_n = int(far.sum())
524        r.clean_offset_ms = float(ci * 1000)
525        r.clean_drift_ppm = float(cs * 1e6)
526        r.clean_jitter_sd_ms = float(cj.std())
527        r.clean_jitter_max_ms = float(np.abs(cj).max())
528    else:
529        r.clean_n = int(far.sum())
530    return r
